简历工坊 · 从零写出你的第一份简历

30 秒科普：简历不是人生履历表，而是一页纸的面试邀约广告——它的唯一目标，是让 HR 在 20 秒内愿意给你一次面试。左边填，右边实时生成你的简历，填完点「打印」就是成品。

先看这个：没经历写不出内容是错觉。课程作业、社团活动、比赛、帮老师做事都算经历，关键是用「做了什么 + 结果」的语言写出来，而不是「参与了很多」。
证件照（可选）
建议 1 寸免冠照（JPG/PNG，≤8MB）。仅保存在本页内存：自动排进右上角、随打印输出、随安全退出存档一起带走。
怎么写一条经历：别写「跟同学做了个网页」，写「课程网页项目（5人团队）：负责商品列表页开发，完成 3 个页面」。公式：项目名（角色）+ 你具体做了什么 + 结果（能加数字最好）。没数字就先空着，别编。
技能的铁律：每写一项，最好经历里能找到证据（项目里用过）。光秃秃的「精通 Office」不如不写——面试官一定会追问「精通到什么程度」。
隐私模式退出流程：点「🚪 安全退出」→ 系统自动把你的草稿（含照片）下载存档到浏览器默认下载位置 → 再清空页面，下一位什么都看不到。想固定存桌面：浏览器设置 → 下载内容 → 位置改为「桌面」，以后每次自动存桌面。手机同理，存档进「下载/文件」。网页本身从不自动存任何东西，也没有服务器记录。

诊断台 · 六维体检你的简历

三种喂料任选：① 直接贴文本；② 把文件（图片 / Word .docx / PDF / txt）拖进文本框，或截图后 Ctrl+V 粘贴（简历框、JD 框都行）；③ 点下方按钮上传。解析都在本机完成（复杂 PDF 会联网下载解析组件，文档本身不离开浏览器）；图片转文字（OCR）需联网。这是「规则粗查」——深度诊断（逐句改写、追问预演）回对话里找 AI 做，那个更狠。

支持 图片 / Word(.docx) / PDF / txt；截图可直接 Ctrl+V 粘贴；老 .doc 请先另存为 .docx

诊断结果

说明：岗位匹配度按 JD 关键词在简历中的覆盖率计算；量化表达按含数字的条目占比；其余维度为规则化粗查。诚信维度无法机器判断，靠你的三问自查——机器永远代替不了这一问。

面试模拟间 · 和虚拟面试官过一遍真实流程

先弄懂流程就不慌了：几乎所有面试都是这五步——自我介绍 → 经历深挖 → 能力/情景题 → 动机题 → 你反问。技术岗常加笔试（算法题或现场写代码），其余岗位多为性格测评（网上的问卷，如实答即可，无对错）。

① 自我介绍② 经历深挖③ 能力/情景题④ 动机题⑤ 反问环节✚ 笔试/测评：技术岗常有，其他岗多为测评
怎么玩：面试官提问 → 你像真面试一样作答（打字，或点 🎤 用语音说，建议每题 80–200 字）→ 每题答完收到「复盘卡」：这题在考察什么、好答案长什么样、四项自查。答完所有题出总结报告。回答里尽量带具体项目名和数字——机器会检测到。语音识别由浏览器联网完成，需 Chrome/Edge。
求职急诊室 · 教练而非枪手：诊断先于改写，每处修改可复核，只改表达不改事实。 · 隐私模式：不自动保存、无服务器记录；「安全退出」会先自动下载草稿再清空页面。 · 手机与电脑均可用，同一 Wi-Fi 下访问本站链接即可。 · 图片 OCR、语音识别与复杂 PDF 解析需联网（文档/图片本身不上传）。 · 深度服务：回到 TeleAgent 对话说「帮我诊断简历」。
